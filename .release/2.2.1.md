# PlexonRanks 2.2.1

PlexonCore 2 lifecycle compatibility patch.

- Supports Core API `>=1.0 <3.0`.
- Fixes successful startup being stranded in `STARTING` under Core 2.
- Uses owner-aware Core 2 state transitions/unregister semantics while retaining Core 1 fallback behavior.
- Pins CI/release builds to PlexonCore 2.0.4 and SHA-256 `61d625a717da9f46ee9231e1970d84b4c317ae12cf4090cdf7c9d39b6a1a9baf`.

Rank requirements, transactions, rewards, LuckPerms synchronization, persistence and PlaceholderAPI behavior are otherwise unchanged.
